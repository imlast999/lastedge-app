# LastEdge App — Configuration Guide

> **Module:** `LastEdge App`  
> **Config File:** `.env`  
> **Template:** `.env.example`  

---

## 1. Environment Variables Reference (`.env`)

### Server & Network Configuration
| Variable | Type | Default | Description |
|---|---|---|---|
| `APP_HOST` | `str` | `0.0.0.0` | Bind host address for the Web Dashboard & Mobile Gateway. |
| `APP_PORT` | `int` | `8080` | Port for the Web Dashboard HTTP server. |
| `TRADING_ENGINE_URL` | `str` | `http://localhost:8081` | Base URL of the LastEdge Trading Engine REST API. |
| `STRATEGY_LAB_URL` | `str` | `http://localhost:8082` | Base URL of the LastEdge Strategy Lab REST API. |
| `API_TIMEOUT_SECONDS` | `float` | `2.5` | Timeout in seconds for backend HTTP calls. |
| `LOG_LEVEL` | `str` | `INFO` | Logging verbosity (`DEBUG`, `INFO`, `WARNING`, `ERROR`). |

### Security & Authentication
| Variable | Type | Default | Description |
|---|---|---|---|
| `DASHBOARD_PIN` | `str` | `1623` | Security PIN required to unlock Dashboard control actions and mobile client access. |
| `APP_API_TOKEN` | `str` | *None* | Shared secret bearer token for API gateway route authentication. |
| `TRADING_API_KEY` | `str` | *None* | API authorization key passed when querying Trading Engine endpoints. |

### Messaging Bot Activation & Controls
| Variable | Type | Default | Description |
|---|---|---|---|
| `ACTIVATE_DISCORD_BOT` | `str` | `on` | Master switch for Discord bot adapter (`on` or `off`). |
| `ACTIVATE_TELEGRAM_BOT` | `str` | `on` | Master switch for Telegram bot adapter (`on` or `off`). |

### Discord Bot Settings
| Variable | Type | Default | Description |
|---|---|---|---|
| `DISCORD_BOT_TOKEN` | `str` | *None* | Discord Application Bot token obtained from Discord Developer Portal. |
| `DISCORD_CHANNEL_ID` | `str` | *None* | Target Discord Channel ID for broadcasting trade alerts and signal notifications. |
| `AUTHORIZED_USER_ID` | `int` | `0` | Primary authorized Discord user ID allowed to execute commands and approve signals. |
| `AUTHORIZED_USER_IDS` | `str` | *None* | Comma-separated list of authorized Discord user IDs (`id1,id2`) for multi-operator environments. |
| `GUILD_ID` | `str` | *None* | Optional Discord server/guild ID for instant command tree synchronization. |

### Telegram Bot Settings
| Variable | Type | Default | Description |
|---|---|---|---|
| `TELEGRAM_BOT_TOKEN` | `str` | *None* | HTTP API Bot token generated by `@BotFather`. |
| `TELEGRAM_CHAT_ID` | `str` | *None* | Authorized personal or group chat ID permitted to interact with the bot. |

---

## 2. Example Configuration (`.env`)

```env
# ── LastEdge App & Web Dashboard Configuration ──────────────────────────────
APP_HOST=0.0.0.0
APP_PORT=8080

# Backend Integration URLs
TRADING_ENGINE_URL=http://localhost:8081
STRATEGY_LAB_URL=http://localhost:8082

# Security & API Authentication
DASHBOARD_PIN=1623
APP_API_TOKEN=let_trade_secret_key_prod
TRADING_API_KEY=let_trade_secret_key_prod

# ── Optional Notification Bots (on / off) ───────────────────────────────────
ACTIVATE_DISCORD_BOT=off
DISCORD_BOT_TOKEN=your_discord_bot_token_here
DISCORD_CHANNEL_ID=your_discord_channel_id_here
AUTHORIZED_USER_ID=739198540177473667
AUTHORIZED_USER_IDS=739198540177473667

ACTIVATE_TELEGRAM_BOT=on
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
TELEGRAM_CHAT_ID=your_telegram_chat_id_here

LOG_LEVEL=INFO
```
