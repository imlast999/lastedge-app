# LastEdge App — Web Dashboard Specification

> **Module:** `LastEdge App`  
> **Source Directories:** `dashboard/`, `services/dashboard_server.py`  

---

## 1. Web Dashboard Features

- **Port**: `8080` (`http://localhost:8080`)
- **Theme**: Dark mode optimized for trading desks with glassmorphic cards.
- **Widgets**:
  - Live Account Equity & Floating PnL counter.
  - Active MT5 Open Positions table with single-click manual close.
  - Risk Engine v2 telemetry & Circuit Breaker status badge.
  - Strategy Lab candidate & experiment viewer.
  - Backend connection status badges (Trading Engine / Strategy Lab).
