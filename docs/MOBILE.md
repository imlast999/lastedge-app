# LastEdge App — Mobile Application (React Native / Expo)

> **Module:** `LastEdge App`  
> **Source Directory:** `mobile-app/`  

---

## 1. Mobile Tech Stack

- **Framework**: React Native with Expo Router (Tabs navigation).
- **Languages**: TypeScript, React 18.
- **Tabs**:
  - `(tabs)/index.tsx`: Overview & live account balance chart.
  - `(tabs)/trades.tsx`: Open positions list and position closing action.
  - `(tabs)/lab.tsx`: Strategy Lab experiments and candidate review.
  - `settings-modal.tsx`: Backend connection URLs and API keys configuration.
